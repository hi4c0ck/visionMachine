# img/

Place the captured screenshots described in [SCREENSHOTS.md](../SCREENSHOTS.md)
in this folder, using exactly these file names:

- `screenshot-composer.png` — the hero image (full composer, populated session)
- `composer-tags.png` — a segment with camera + lighting tags selected
- `preview-ruler.png` — generated video in the top preview with the frame ruler
- `generation-progress.png` — the per-stage generation progress modal
- `projects-panel.png` — projects/sessions sidebar with stored data

Optional: `pipe-composition.gif` — a short clip of pipes connecting into one
sequence.

Keep each file small (screenshots < 300 KB, any GIF < 3 MB). The README
references them relative to the repo root (`img/<name>.png`), which renders
on GitHub and in the checked-out repo.
