# VisionMachine Desktop App
## Tauri + Svelte + Rust - Production Ready

## Quick Start

```bash
# 1. Install dependencies
cd src-tauri && cargo install tauri-cli --version "^2"
cd ../src/frontend && npm install

# 2. Run development
cargo tauri dev

# 3. Build for production
cargo tauri build
```

## What You Get
- Native Windows desktop app (.exe)
- SQLite database with WAL mode
- 14 Tauri commands for CRUD operations
- MVI pattern with reactive state
- Dual-instance Composer UI
- Complete security validation
