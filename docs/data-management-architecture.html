Data Management System Architecture

System Overview

🗄️

SQLite Storage Layer

  • profiles - User accounts & settings
  • projects - Top-level containers
  • sessions - Work environments
  • composers - YAML/JSON configs
  • artifacts - Linked media files
  • app_settings - Global config
struct Database { pool: SqlitePool, storage_path: PathBuf, }
🎯

MVI ViewModels

  • FrameViewModel - GPU rendering, video playback
  • ProjectViewModel - List navigation
  • ProfileViewModel - User switching
  • ComposerViewModel - Dual-instance support
  • ToolsViewModel - Tool registry
pub struct ViewModel { state: Arc<Mutex<ViewState>>, loading: Arc<watch::Sender<bool>>, opacity: Arc<watch::Sender<f32>>, visible: Arc<watch::Sender<bool>>, }
⚙️

Section Controllers

  • FrameController - Overlay control, resolution
  • ProjectsController - Expand/collapse tree
  • ProfileController - Login/logout flow
  • ComposerController - Pipe management
  • ToolsController - Tool activation
💾

Storage Manager

  • Default: Windows temp directory
  • Configurable via Settings panel
  • Triggers app restart on change
  • Async writer for Composer data
  • Debounced saves (300ms)

Database Schema

Table Purpose Key Fields Relationship
profiles User accounts id, name, email, avatar_path, settings 1:N projects
projects Top-level containers id, profile_id, name, logo_path N:1 profiles, 1:N sessions
sessions Work environments id, project_id, name, state N:1 projects, 1:1 composer
composers Generator config id, session_id, config_json, version N:1 sessions
artifacts Linked media files id, type, file_path, metadata N:1 sessions/projects/profiles
app_settings Global config key, value -

Composer Data Model

// Composer Structure pub struct Composer { pub id: String, pub session_id: String, pub name: String, pub pipes: Vec<Pipe>, pub state: ComposerState, // Empty, Loading, Ready, Generating... } // Pipe - named segment in generation chain pub struct Pipe { pub id: String, pub name: String, pub order: usize, pub config: BaseConfig, // model, temperature, tokens... pub keyframes: Vec<KeyframeImage>, // up to 3 reference images pub prompt_rows: Vec<PromptRow>, } // PromptRow - XML-tagged values with hierarchy pub struct PromptRow { pub id: String, pub tag: String, // e.g., "<subject>", "<style>" pub value: String, pub parent_id: Option<String>, pub children: Vec<String>, pub weight: f32, }
